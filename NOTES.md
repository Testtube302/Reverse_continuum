## Facts established
- `.bm2` = 8-bit BMP, some RLE8. Black (0,0,0) = transparent. `.wa2` = 8-bit mono 22050 Hz WAV.
- ships.bm2: 36x36 frames, 10 per row, frame = ship*40 + direction(0..40, 0=up, clockwise).
- tiles.bm2: 304x160 = 19x10 tiles of 16px; tile id N -> index N-1. Ids >190 are special objects
  drawn from other sheets (not done yet).
- Units: thrust*10/16 tiles/s^2; speed/160 tiles/s; rotation/400 turns/s; energy rates per 10 s.
  Bounce scales velocity by 16/BounceFactor (SVS = 22); no extra damping on consecutive ticks.
- Original installer: https://www.getcontinuum.com/downloads/continuum/Continuum040Setup.zip
  (Inno Setup; unpack with `innoextract`, no Wine needed). Continuum.exe is packed — don't touch.
- Reference sources (clone outside repo): plushmonkey/nullspace (MIT, C),
  gigamon-dev/SubspaceServer (C#; `src/SubspaceServer/Zone/conf/svs` = standard settings).

- Settings packet 0x0F = 1428 bytes: ship blocks of 144 bytes from offset 4 (radius bits at +28 >>3,
  rotation/thrust/speed max @+40.., initial @+50.., AB energy @+70); BounceFactor @1272.
- Servers relay ship positions only to players whose (spectator) position is nearby.
- SS.NET security request every 60 s; SecurityKickOff=0 → exe mismatch is only logged.
- Damage settings arrive ×1000 (BulletDamageLevel=100 in conf → 100000 in packet).
- Arena conf overrides svs: arenas/(default)/arena.conf sets PrizeFactor=10000, PrizeDelay=700,
  MinimumVirtual=10. Center of smallmape.lvl is a safe zone (no firing; weapons vanish).
- Bombs block guns for BombFireDelay unless EmpBomb (looks like "guns don't fire" — it's correct).
- Keys (Continuum defaults): Ctrl gun, Tab bomb, Shift+Tab mine, Del multifire, Shift afterburner.
- `cargo build` doesn't rebuild examples — use --all-targets before running examples/bot.
